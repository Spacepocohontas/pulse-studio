# Pulse Studio

Audio-reactive visualizer + mini DJ deck + live capture.

## Features
- Upload audio/video (mp3, wav, mp4, webm, mov)
- Real-time beat-reactive canvas modes: spectrum, orbit, tunnel, particles, waveform, neon-grid
- Optional prompt steers color/mood/motion
- Mute original audio & layer your own track
- Capture canvas + audio to WebM download
- Local project save + activity log (browser storage)

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Static Vite app — `npm run build` then host `dist/`.
